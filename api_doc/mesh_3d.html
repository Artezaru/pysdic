Mesh3D class#

class pysdic.geometry.Mesh3D(vertices, connectivity, vertices_properties=None, elements_properties=None, internal_bypass=False)[source]#

A Mesh is a collection of vertices (PointCloud3D) and connectivity information that defines the elements of the mesh.

This is an abstract base class for 3D meshes.

The vertices are represented as a PointCloud3D instance with shape (N, 3), The connectivity is represented as a numpy ndarray with shape (M, K), where N is the number of vertices (n_vertices), M is the number of elements (n_elements), and K is the number of vertices per element (n_vertices_per_element).

The coordinates of a point into the mesh can be accessed by the natural coordinates in the reference element. The number of natural coordinates \((\xi, \eta, \zeta, ...)\) depends on the type of element and is noted as d (the topological dimension of the element) accessible through the property n_dimensions.

Lets consider a mesh with K vertices per element, and d natural coordinates. Lets \(X\) be the coordinates of a point in the mesh. The transformation from natural coordinates to global coordinates is given by:

\[X = \sum_{i=1}^{K} N_i(\xi, \eta, \zeta, ...) X_i\]

where \(N_i\) are the shape functions associated with each vertex, and \(X_i\) are the coordinates of the vertices of the element.

The subclasses must implement the following attributes and methods:

  • (class property) _n_vertices_per_element: int, the number of vertices K per element.

  • (class property) _n_dimensions: int, the topological dimension d of the elements.

  • (class property) _meshio_cell_type: str, the cell type used by meshio for this type of element.

  • (method) shape_functions: Callable[[numpy.ndarray], [numpy.ndarray, numpy.ndarray]], a method to compute the shape functions at given natural coordinates (and optional Jacobians).

The mesh can also store additional properties for the elements and vertices through the dictionaries:

  • _vertices_properties: dict, a dictionary to store properties of the vertices, each property is a numpy ndarray with float64 dtype of shape (N, A) where N is the number of vertices and A is the number of attributes for that property.

  • _elements_properties: dict, a dictionary to store properties of the elements, each property is a numpy ndarray with float64 dtype of shape (M, B) where M is the number of elements and B is the number of attributes for that property.

Parameters:

  • vertices (PointCloud3D) – The vertices of the mesh as a PointCloud3D instance with shape (N, 3).

  • connectivity (numpy.ndarray) – The connectivity of the mesh as a numpy ndarray with shape (M, K), where M is the number of elements and K is the number of vertices per element.

  • vertices_properties (Optional[dict], optional) – A dictionary to store properties of the vertices, each property should be a numpy ndarray of shape (N, A) where N is the number of vertices and A is the number of attributes for that property, by default None.

  • elements_properties (Optional[dict], optional) – A dictionary to store properties of the elements, each property should be a numpy ndarray of shape (M, B) where M is the number of elements and B is the number of attributes for that property, by default None.

  • internal_bypass (bool, optional) – If True, internal checks are skipped for better performance, by default False.

Instantiate and export Mesh3D object#

The Mesh3D class is an ABC (Abstract Base Class) and cannot be instantiated directly.

By default, the meshes are created from a set of vertices and connectivity. The vertices are represented as a pysdic.geometry.PointCloud3D object, and the connectivity is represented as a NumPy array of shape (M, K), where each row contains the indices of the vertices that form an element.

The subclasses of Mesh3D can also use the following methods to instantiate a Mesh3D object from different file formats.

Mesh3D.from_meshio(mesh[, load_properties])

Create a Mesh3D instance from a meshio Mesh object.

Mesh3D.from_vtk(filename[, load_properties])

Create a Mesh3D instance from a VTK file.

Mesh3D.from_empty()

Create an empty Mesh3D instance.

Mesh3D.from_mesh(other[, load_properties])

Create a Mesh3D instance from another Mesh3D instance.

The Mesh3D class provides methods to export the mesh to various file formats.

Mesh3D.to_meshio([save_properties])

Convert the Mesh3D instance to a meshio Mesh object.

Mesh3D.to_vtk(filename[, save_properties])

Write the Mesh3D instance to a VTK file.

Accessing Mesh3D attributes#

The public attributes of a Mesh3D object can be accessed using the following properties:

Mesh3D.internal_bypass

When enabled, internal checks are skipped for better performance.

Mesh3D.connectivity

Get or set the connectivity of the mesh.

Mesh3D.elements

Alias for connectivity property.

Mesh3D.n_vertices

Get the number of vertices in the mesh.

Mesh3D.n_elements

Get the number of elements in the mesh.

Mesh3D.n_vertices_per_element

Get the number of vertices per element in the mesh.

Mesh3D.n_dimensions

Get the topological dimension of the elements in the mesh.

Mesh3D.meshio_cell_type

Get the cell type used by meshio for this type of element.

Mesh3D.vertices

The vertices of the mesh in an PointCloud3D instance.

Manage vertices and elements properties#

Several properties can be associated with the vertices and elements of the mesh. These properties can be accessed and modified using the following methods:

Mesh3D.clear_elements_properties()

Clear all properties associated with the elements of the mesh.

Mesh3D.clear_vertices_properties()

Clear all properties associated with the vertices of the mesh.

Mesh3D.clear_properties()

Clear all properties of the mesh, including mesh properties, vertices properties, and elements properties.

Mesh3D.get_elements_property(key)

Get a property associated with the elements of the mesh with shape (M, B)

Mesh3D.get_vertices_property(key)

Get a property associated with the vertices of the mesh with shape (N, A).

Mesh3D.remove_elements_property(key)

Remove a property associated with the elements of the mesh.

Mesh3D.remove_vertices_property(key)

Remove a property associated with the vertices of the mesh.

Mesh3D.set_elements_property(key, value)

Set a property associated with the elements of the mesh with shape (M, B).

Mesh3D.set_vertices_property(key, value)

Set a property associated with the vertices of the mesh with shape (N, A).

Mesh3D.list_elements_properties()

List all keys of the properties associated with the elements of the mesh.

Mesh3D.list_vertices_properties()

List all keys of the properties associated with the vertices of the mesh.

Add, remove or modify vertices or connectivity of the Mesh3D objects#

To manipulate only the geometry of the mesh, access the vertices attribute (pysdic.geometry.PointCloud3D) and use its methods.

The topology of the mesh can be modified using the following methods:

Mesh3D.add_elements(new_connectivity)

Add new elements to the mesh by appending new connectivity entries.

Mesh3D.add_vertices(new_vertices)

Add new vertices to the mesh by appending new vertex coordinates.

Mesh3D.are_used_vertices(vertex_indices)

Check if multiple vertices are used in the connectivity of the mesh.

Mesh3D.is_empty()

Check if the mesh is empty (i.e., has no vertices or no elements).

Mesh3D.keep_elements(element_indices)

Keep only the specified elements in the mesh by specifying their indices in the connectivity array.

Mesh3D.remove_elements(element_indices)

Remove elements from the mesh by specifying their indices in the connectivity array.

Mesh3D.remove_unused_vertices()

Remove all vertices that are not used in the connectivity of the mesh.

Mesh3D.remove_vertices(vertex_indices)

Remove vertices from the mesh by specifying their indices.

Mesh3D geometric computations and interpolations#

Some methods are provided to perform geometric computations and property interpolations on Mesh3D objects:

Mesh3D.copy()

Create a deep copy of the Mesh3D instance.

Mesh3D.get_vertices_coordinates(element_indices)

Get the coordinates of the vertices for the specified elements.

Mesh3D.interpolate_property_at_natural_coordinates(...)

Interpolate a vertices property at given natural coordinates and element indices.

Mesh3D.interpolate_property_at_integration_points(...)

Interpolate a vertices property at given natural coordinates and element indices from an IntegrationPoints instance.

Mesh3D.integration_points_to_global_coordinates(...)

Transform natural coordinates to global coordinates from an IntegrationPoints instance.

Mesh3D.natural_to_global_coordinates(...)

Transform natural coordinates to global coordinates for specified natural coordinates and element indices.

Mesh3D.project_integration_property_to_vertices(...)

Project an integration points property to the vertices of the mesh.

Mesh3D.shape_functions(natural_coords[, ...])

Compute the shape functions at given natural coordinates.

Mesh3D.shape_functions_matrix(...[, ...])

Compute the shape functions matrix at given natural coordinates.

Mesh3D.validate()

Validate the mesh by performing internal checks on vertices and connectivity.
