SurfaceMesh class#

class pysdic.geometry.SurfaceMesh(vertices, connectivity, *, vertices_properties=None, elements_properties=None, internal_bypass=False)[source]#

Abstract Base Class for 2D topological Meshes (\(K=2\)).

This class extends the Mesh abstract base class to represent 2D meshes. It serves as a base for specific surfacique mesh implementations.

This mesh is characterized by having 2D elements (e.g., triangles, quadrilaterals) defined in a space of dimension \(E >= 2\).

The coordinates of a point into the mesh can be accessed by the natural coordinates in the reference element. The number of natural coordinates \((\xi, \eta)\) with a topological dimension of \(K=2\).

Parameters:

  • vertices (PointCloud) – The vertices of the mesh as a PointCloud instance with shape (\(N_v\), :math`E`), where \(N_v\) is the number of vertices and \(E\) is the embedding dimension.

  • connectivity (numpy.ndarray) – The connectivity of the mesh as a numpy ndarray with shape (\(N_e\), \(N_{vpe}\)), where \(N_e\) is the number of elements and \(N_{vpe}\) is the number of vertices per element.

  • vertices_properties (Optional[dict], optional) – A dictionary to store properties of the vertices, each property should be a numpy ndarray of shape (\(N_v\), :math`A`) where \(N_v\) is the number of vertices and \(A\) is the number of attributes for that property, by default None.

  • elements_properties (Optional[dict], optional) – A dictionary to store properties of the elements, each property should be a numpy ndarray of shape (\(N_e\), :math`B`) where \(N_e\) is the number of elements and \(B\) is the number of attributes for that property, by default None.

  • internal_bypass (bool, optional) – If True, internal checks are bypassed for better performance, by default False.

Instantiate and export SurfaceMesh object#

The SurfaceMesh class is an ABC (Abstract Base Class) and cannot be instantiated directly.

By default, the meshes are created from a set of vertices and connectivity (see example below). The vertices are represented as a pysdic.geometry.PointCloud object, and the connectivity is represented as a NumPy array of shape (\(N_e\), \(N_{vpe}\)), where each row contains the indices of the vertices that form an element.

See the methods of the parent class pysdic.geometry.Mesh for more details on how to instantiate and export SurfaceMesh objects.

Additional SurfaceMesh attributes#

For the common attributes inherited from pysdic.geometry.Mesh, see the class documentation of pysdic.geometry.Mesh.

An additional elements_property under the key "uvmap" can be used to store the UV mapping of the mesh. The UV mapping associates 2D coordinates at each vertex of each element in order to map a texture onto the surface. The property can be accessed using the following attribute :

SurfaceMesh.elements_uvmap

Get or set the UV mapping of each triangular element.

Manipulating SurfaceMesh objects#

To manipulate only the geometry of the mesh, access the vertices attribute (pysdic.geometry.PointCloud) and use its methods. For the common methods inherited from pysdic.geometry.Mesh, see the class documentation of pysdic.geometry.Mesh for other inherited methods.

Visualize SurfaceMesh objects#

The SurfaceMesh class provides methods to visualize the mesh and its properties using PyVista for meshes with embedded dimension \(E \leq 3\).

SurfaceMesh.visualize([vertices_color, ...])

Visualize the surface mesh using PyVista (only for \(E \leq 3\) meshes).

SurfaceMesh.visualize_integration_points(...)

Visualize the 3D surface mesh with integration points using PyVista.

SurfaceMesh.visualize_texture(texture[, ...])

Visualize the texture of the mesh using a texture image.

SurfaceMesh.visualize_vertices_property([...])

Visualize a vertex property on the 3D surface mesh using PyVista.
