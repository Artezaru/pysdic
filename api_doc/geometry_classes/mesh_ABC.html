Mesh class#

class pysdic.geometry.Mesh(vertices, connectivity, vertices_properties=None, elements_properties=None, internal_bypass=False)[source]#

A Mesh is a collection of vertices (PointCloud) and connectivity information that defines the elements of the mesh.

This is an abstract base class for meshes.

The vertices are represented as a PointCloud instance with shape (\(N_v\), :math`E`), where \(N_v\) is the number of vertices (n_vertices) and \(E\) is the embedding dimension (n_dimensions). The connectivity is represented as a numpy ndarray with shape (\(N_e\), \(N_{vpe}\)), where \(N_e\) is the number of elements (n_elements), and \(N_{vpe}\) is the number of vertices per element (n_vertices_per_element).

The coordinates of a point into the mesh can be accessed by the natural coordinates in the reference element. The number of natural coordinates \((\xi, \eta, \zeta, ...)\) depends on the type of element and is noted as \(K\) (the topological dimension of the element) accessible through the property n_topological_dimensions.

Lets consider a mesh with \(N_{vpe}\) vertices per element, and \(K\) natural coordinates. Lets \(X\) be the coordinates of a point in the mesh. The transformation from natural coordinates to global coordinates is given by:

\[X = \sum_{i=1}^{N_{vpe}} N_i(\xi, \eta, \zeta, ...) X_i\]

where \(N_i\) are the shape functions associated with each vertex, and \(X_i\) are the coordinates of the vertices of the element.

See also

  • /geometry/shape_functions for more information on shape functions.

The subclasses must define the following class attributes:

  • _expected_N_vpe : int

  • _expected_K : int

  • _meshio_cell_type : str

  • _shape_functions_meth : Callable

Parameters:

  • vertices (PointCloud) – The vertices of the mesh as a PointCloud instance with shape (\(N_v\), \(E\)), where \(N_v\) is the number of vertices and \(E\) is the embedding dimension.

  • connectivity (numpy.ndarray) – The connectivity of the mesh as a numpy ndarray with shape (\(N_e\), \(N_{vpe}\)), where \(N_e\) is the number of elements and \(N_{vpe}\) is the number of vertices per element.

  • vertices_properties (Optional[dict], optional) – A dictionary to store properties of the vertices, each property should be a numpy ndarray of shape (\(N_v\), :math`A`) where \(N_v\) is the number of vertices and \(A\) is the number of attributes for that property, by default None.

  • elements_properties (Optional[dict], optional) – A dictionary to store properties of the elements, each property should be a numpy ndarray of shape (\(N_e\), :math`B`) where \(N_e\) is the number of elements and \(B\) is the number of attributes for that property, by default None.

  • internal_bypass (bool, optional) – If True, internal checks are bypassed for better performance, by default False.

Instantiate and export Mesh object#

The Mesh class is an ABC (Abstract Base Class) and cannot be instantiated directly.

By default, the meshes are created from a set of vertices and connectivity. The vertices are represented as a pysdic.geometry.PointCloud object, and the connectivity is represented as a NumPy array of shape (\(N_e\), \(N_{vpe}\)), where each row contains the indices of the vertices that form an element and \(N_e\) is the number of elements and \(N_{vpe}\) is the number of vertices per element.

The subclasses of Mesh can also use the following methods to instantiate a Mesh object from different file formats.

Mesh.from_meshio(mesh[, load_properties])

Create a Mesh instance from a meshio.Mesh object.

Mesh.from_vtk(filename[, load_properties])

Create a Mesh instance from a VTK file.

The Mesh class provides methods to export the mesh to various file formats.

Mesh.to_meshio([save_properties])

Convert the Mesh instance to a meshio.Mesh object.

Mesh.to_vtk(filename[, save_properties])

Write the Mesh instance to a VTK file.

Accessing Mesh attributes#

The public attributes of a Mesh object can be accessed using the following properties:

Mesh.internal_bypass

When enabled, internal checks are skipped for better performance.

Mesh.connectivity

Get or set the connectivity of the mesh.

Mesh.elements

Alias for connectivity property.

Mesh.n_vertices

Get the number of vertices \(N_v\) in the mesh (same as N_v).

Mesh.N_v

Alias for n_vertices property.

Mesh.n_elements

Get the number of elements \(N_e\) in the mesh (same as N_e).

Mesh.N_e

Alias for n_elements property.

Mesh.n_vertices_per_element

Get the number of vertices per element \(N_{vpe}\) in the mesh (same as N_vpe).

Mesh.N_vpe

Alias for n_vertices_per_element property.

Mesh.n_dimensions

Get the embedding dimension \(E\) of the mesh (same as E).

Mesh.E

Alias for n_dimensions property.

Mesh.n_topological_dimensions

Get the topological dimension \(K\) of the elements in the mesh (same as K).

Mesh.K

Alias for n_topological_dimensions property.

Mesh.meshio_cell_type

Get the cell type used by meshio for this type of element.

Mesh.vertices

The vertices of the mesh in an PointCloud instance.

Manage vertices and elements properties#

Several properties can be associated with the vertices and elements of the mesh. These properties can be accessed and modified using the following methods:

Mesh.clear_elements_properties()

Clear all properties associated with the elements of the mesh.

Mesh.clear_vertices_properties()

Clear all properties associated with the vertices of the mesh.

Mesh.clear_properties()

Clear all properties of the mesh, including mesh properties, vertices properties, and elements properties.

Mesh.get_elements_property(key)

Get a property associated with the elements of the mesh with shape (\(N_e\), B)

Mesh.get_vertices_property(key)

Get a property associated with the vertices of the mesh with shape (\(N_v\), A).

Mesh.remove_elements_property(key)

Remove a property associated with the elements of the mesh.

Mesh.remove_vertices_property(key)

Remove a property associated with the vertices of the mesh.

Mesh.set_elements_property(key, value)

Set a property associated with the elements of the mesh with shape (\(N_e\), B).

Mesh.set_vertices_property(key, value)

Set a property associated with the vertices of the mesh with shape (\(N_v\), A).

Mesh.list_elements_properties()

List all keys of the properties associated with the elements of the mesh.

Mesh.list_vertices_properties()

List all keys of the properties associated with the vertices of the mesh.

Add, remove or modify vertices or connectivity of the Mesh objects#

To manipulate only the geometry of the mesh, access the vertices attribute (pysdic.geometry.PointCloud) and use its methods.

The topology of the mesh can be modified using the following methods:

Mesh.add_elements(new_connectivity)

Add new elements to the mesh by appending new connectivity entries.

Mesh.add_vertices(new_vertices)

Add new vertices to the mesh by appending new vertex coordinates.

Mesh.are_used_vertices(vertex_indices)

Check if multiple vertices are used in the connectivity of the mesh.

Mesh.is_empty()

Check if the mesh is empty (i.e., has no vertices or no elements).

Mesh.keep_elements(element_indices)

Keep only the specified elements in the mesh by specifying their indices in the connectivity array.

Mesh.remove_elements(element_indices)

Remove elements from the mesh by specifying their indices in the connectivity array.

Mesh.remove_unused_vertices()

Remove all vertices that are not used in the connectivity of the mesh.

Mesh.remove_vertices(vertex_indices)

Remove vertices from the mesh by specifying their indices.

Mesh geometric computations and interpolations#

Some methods are provided to perform geometric computations and property interpolations on Mesh objects:

Mesh.copy()

Create a deep copy of the Mesh instance.

Mesh.shape_functions(*args, **kwargs)

Method to compute the shape functions and their first derivatives for the mesh elements.

Mesh.validate()

Validate the mesh by performing internal checks on vertices and connectivity.

See also

  • pysdic.geometry.construct_jacobian() : Function to construct the Jacobian matrix for coordinate transformations using shape functions.

  • pysdic.geometry.interpolate_property() : Function to interpolate properties within elements using shape functions.

  • pysdic.geometry.project_property_to_vertices() : Function to project properties from integration points back to element nodes using shape functions.

Surfacique Mesh classes (SurfaceMesh)#

The package provides a pysdic.geometry.SurfaceMesh class that inherits from the pysdic.geometry.Mesh ABC. This class is designed to represent 2D topological meshes (\(K=2\)) used for SDIC computations.
