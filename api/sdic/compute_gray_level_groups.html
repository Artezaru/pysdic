pysdic.compute_gray_level_groups#

compute_gray_level_groups(mesh, integration_points, neighborhood=None)[source]#

Compute the groups of integration points for the statistics of the gray level corrections.

  • neighborhood=None: a single group with all the points (global correction).

  • neighborhood=n: one group per element. The gray levels of the points of an element are corrected with the statistics of the points located in the elements within a distance \(n\) (see pysdic.fem.compute_elements_neighborhood()): 0 for the element alone, 1 for the element and the elements sharing a vertex with it, …

Only the neighborhood of the elements is computed (not the points of each group, see GrayLevelGroups). The groups only depend on the connectivity of the mesh and on the elements of the points: compute them once and give them to all the terms built with the same mesh and integration points (gray_level_groups of pysdic.SDICCorrelationTerm).

Parameters:

  • mesh (pysdic.Mesh) – The mesh in which the points are located.

  • integration_points (pysdic.IntegrationPoints) – The integration points, located in the mesh.

  • neighborhood (Optional[Integral], optional) – The size of the neighborhood (non-negative), or None for a global correction.

Returns:

The groups of the points.

Return type:

GrayLevelGroups

Raises:

ValueError – If the points are not consistent with the mesh or not all located.
