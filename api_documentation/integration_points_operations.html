Operations on Integration Points (interpolation, projection, etc.)#

Table of Contents

  • Description

  • Implemented Functions

Description#

The package pysdic provides functions to perform operations for various types of elements used in finite element analysis.

In a space of dimension \(E\) with a mesh constituted of \(N_{e}\) elements and \(N_{v}\) nodes/vertices. The mesh is composed of \(K\)-dimensional elements (with \(K \leq E\)) defined by \(N_{vpe}\) nodes for each element.

The objective of these operations is to interpolate or project values defined at integration points to nodes or other points in space, and vice versa.

If we consider a property \(P\) defined at the vertices of the elements, we can interpolate this property at any point within the element using shape functions:

\[P(\xi, \eta, \zeta, ...) = \sum_{i=1}^{N_{vpe}} N_i(\xi, \eta, \zeta, ...) P_i\]

where \(P\) is the interpolated value at the point, \(N_i\) are the shape functions, and \(P_i\) are the nodal values.

See also

  • Shape Functions Collection (1D, 2D, 3D) for shape functions definitions and details.

Implemented Functions#

The following functions are implemented in this module:

assemble_shape_function_matrix(...[, ...])

Construct the matrix of shape functions at given integration points within elements, from \((N_{p}, N_{vpe})\) to \((N_{p}, N_{v})\) with zero-filling for non-associated nodes/vertices.

construct_jacobian(...)

Construct the Jacobian matrix \(J\) of the transformation from natural coordinates \((\xi, \eta, \zeta, ...)\) to global coordinates \((x, y, z, ...)\).

derivate_property(property_array, ...[, ...])

Derivate a property defined at the nodes of a mesh to given integration points within elements with respect to global coordinates \((x,y,z,...)\) using shape function derivatives.

interpolate_property(property_array, ...[, ...])

Interpolate a property defined at the nodes of a mesh to given integration points within elements using shape functions.

project_property_to_vertices(property_array, ...)

Project a property defined at integration points within elements back to the nodes of a mesh using shape functions.

remap_vertices_coordinates(...[, skip_m1, ...])

Remap the global coordinates of the vertices to given integration points within elements based on the element connectivity.
